# neuroviva-app

App web mobile-first (React + Vite).

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the dev server.

### `npm run build`

Builds the production bundle.

### `npm run preview`

Previews the production build locally.

### `npm test`

Runs unit/integration tests via Vitest.

## Notes

- O app foi refatorado para usar rotas (`react-router-dom`) e layout responsivo (sem “simulador de celular”).
